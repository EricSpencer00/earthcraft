What happens to your tiles

  1. Each finished tile is uploaded to your one pull request on the dataset.
  2. A validator checks every file and comments PASS or FAIL.
  3. The owner merges it, and the tiles appear on the map.

Everything stays in ~/.earthcraft. Delete that folder to remove it. Read the script · Full guide
