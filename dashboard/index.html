    About Earthcraft

    Earthcraft is the whole Earth in Minecraft, at real size: one block is one metre.

    The land is shaped from public elevation data. Buildings come from lidar (laser scans taken from the air) and OpenStreetMap outlines.

    Where it starts

    The build begins with the Chicago area, about 2,600 km² so far, and keeps growing outward from there.

    Look around

    1. Select any shaded square on the map, or search for a place.
    2. Choose View blocks in 3D to orbit or walk through the real Minecraft blocks.

    Or open the 3D viewer at the Water Tower.

    Get the data

    The world is published as Minecraft Java region files in the Earthcraft dataset on Hugging Face. The code is on GitHub.

    Still to come: street-level detail such as facade colors, windows and trees.
