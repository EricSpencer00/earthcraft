THE LONG VIEW

Progress follows evidence.

Earthcraft does not need to write every block on Earth before a place can exist. It needs a stable global address, immutable source extracts, precise surfaces, and an on-demand cache that can replay the same tile anywhere.

  1. 01 / CatalogIndex sources once, then hand bounded extracts to workers.
