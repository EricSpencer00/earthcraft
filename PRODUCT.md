# Product

## Register

product

## Users and purpose

Earthcraft lets visitors explore geographically grounded Minecraft terrain,
inspect real blocks and follow the generation of new tiles. Contributors use
the same public site to understand what has been published and what remains
in the build queue. The README and docs/SITE.md define this existing scope.

## Personality

Measured, geographic, plain-spoken. The map and actual generated blocks carry
the experience. Coverage is partial Chicagoland at one metre per block.

## Principles

- Show generated output and its source rather than implying complete coverage.
- Distinguish published tiles, the installed save and host telemetry.
- Label dates and missing evidence. A stale report is not live health.
- Keep data browsing lightweight and use the existing static site and dataset.

## Accessibility

Retain the site's keyboard navigation, visible focus, text status, semantic
labels and responsive layouts. Existing browser checks establish these
conventions. Color is accompanied by text; reduced motion is respected.

## Anti-references

Avoid promotional counters, fabricated terrain previews and decorative admin
dashboards. Extend the existing map and block viewer vocabulary.
