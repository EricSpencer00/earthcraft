# Product

## Users and purpose

Earthcraft helps people turn a bounded place on Earth into a Minecraft world
while keeping the measurements and missing information visible. The dashboard
is for watching a local run without pretending that bytes on disk equal a
finished or accurate world.

## Principles

Show measured progress, distinguish source acquisition from world output, keep
the default pipeline deterministic, preserve source uncertainty, and never
represent a draft as a verified reconstruction. Chicago is the current working
example; a global atlas is a longer-term idea.

## Design direction

Use a readable atlas and an activity ledger. Prefer plain labels, keyboard-
accessible controls, no decorative animation, and text equivalents for map
state. Avoid fabricated percentage completion and imagery that resembles a
completed world when no chunks exist.
