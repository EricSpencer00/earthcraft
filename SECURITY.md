# Security policy

Please do not put secrets, access tokens, private coordinates, personal
photographs, or other sensitive material in a public issue or pull request.

If private vulnerability reporting is enabled for the GitHub repository, use
GitHub's private reporting form. If it is not enabled, open an issue with only
a short, non-sensitive description and say that a private channel is needed;
do not publish exploit details or credentials. This file should be updated if
the repository gains a dedicated security contact.

Earthcraft also treats source terms and personal location data as security
concerns. A patch that accidentally commits a raw download or an absolute
machine path should be reported and removed from the public branch promptly.
