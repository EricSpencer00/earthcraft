# Earthcraft visual system

This records the existing dashboard, rather than introducing a new brand.

- Light map-workbench surface for visitors inspecting geography in a browser.
- Source Serif 4 for the Earthcraft wordmark and editorial headings; Libre
  Franklin for controls and body text. Both are already self-hosted.
- Restrained forest green with paper and gray-green surfaces. Amber denotes
  delayed information, rust denotes failure; status is always written too.
- A compact header, direct navigation and thin structural rules. Data uses
  aligned rows and tabular numerals, not a grid of metric cards.
- The pipeline view pairs an actual block excerpt with a chronological
  publication list. At narrow widths those sections stack in reading order.
- Visible focus and 44-pixel actions follow dashboard/style.css conventions.

For the pipeline addition, an actual data-driven block preview replaces the
need for illustration or generated visual assets.
