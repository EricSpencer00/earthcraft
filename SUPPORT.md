# Getting help

Earthcraft is an experimental repository, so the most useful support request
is a reproducible one. Open a GitHub issue and include:

- the operating system, Python version, and Minecraft version if relevant;
- the command you ran;
- the complete error and the first useful lines before it;
- whether the offline test suite passes; and
- whether the input was synthetic, public, or your own private data.

Do not attach credentials, private coordinates, personal photographs, raw map
extracts, or generated worlds. Replace private paths and locations with a
short placeholder and explain the shape of the input instead.

If the question is about a source provider, include the source name and the
terms you were working under. “It was available in a browser” is not enough
to establish redistribution permission.
