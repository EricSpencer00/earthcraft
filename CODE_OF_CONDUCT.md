# Contributor Covenant Code of Conduct

## Our pledge

We want Earthcraft to be a place where people can contribute careful work,
ask basic questions, disagree about evidence, and change their minds without
being mocked or harassed. We pledge to make participation in this project a
welcoming experience for everyone.

## Our standards

Positive behaviour includes being considerate, explaining disagreement,
crediting other people's work, and accepting corrections. Unacceptable
behaviour includes harassment, discrimination, personal attacks, doxxing,
publishing private data, sexualised attention, and deliberate disruption.

## Enforcement

Report a problem to the repository maintainers through a private GitHub
channel when one is available. If it is not available, open an issue with no
private details and ask for a private contact. Reports will be handled as
confidentially as the available channel permits.

This code of conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.
